# Remnant Save Manager — русская версия

Локальная русификация [RemnantSaveManager](https://github.com/Razzmatazzz/RemnantSaveManager) для **Remnant: From the Ashes**. Исходный проект и лицензия GPL-3.0 сохранены.

## Запуск

Готовая программа находится в папке dist/RemnantSaveManager-ru. Запустите RemnantSaveManager.exe. Для переноса на другой компьютер распакуйте dist/RemnantSaveManager-ru.zip.

Требуется Windows с .NET Framework 4.7.2 или новее. Сборка проверена с .NET Framework 4.8.

Для анализа нужны сохранения игры. Обычная папка: %LOCALAPPDATA%\Remnant\Saved\SaveGames. Папки сохранений, игры и резервных копий выбираются на вкладке «Настройки». Перед восстановлением сохранения закройте игру.

## Что переведено

- Окна, вкладки, меню, кнопки, подсказки, заголовки таблиц, диалоги и журнал.
- Все предметы, события, миры, локации, классы персонажей и описания условий получения из комплектного справочника версии 40.
- Категории предметов, режимы игры, данные кампании, приключений и дополнений.
- Отчёты Markdown и данные, копируемые в буфер обмена.
- Даты, числа и язык потоков установлены в ru-RU.

Русский каталог Resources/RussianLocalization.xml встроен непосредственно в EXE. Исходный GameInfo.xml также встроен как запасной справочник. Внешний файл рядом с программой используется при наличии; запуск из другой рабочей папки поддерживается.

Внутренние ключи сохранений, пути файлов и пользовательские названия копий сохранены. Отображаемые названия переведены отдельно. Ссылки на статьи об игровых предметах используют английские названия, чтобы открывать нужные страницы. Названия переведены для этой версии; совпадение каждого названия с официальным переводом игры не заявляется.

Обновление GameInfo.xml сохраняет имеющийся русский перевод. Для неизвестных событий и предметов, которых нет в комплектном каталоге, отображается русская отметка и исходный идентификатор; новые записи требуют дополнения русского каталога. Новые описания от сервера также требуют перевода. Проверка обновлений программы ведёт к русским релизам этого репозитория. Обновления игрового справочника загружаются из оригинального проекта.

## Повторная сборка

Из корня репозитория выполните:

    .\Build.ps1

Скрипт загружает закреплённые версии компилятора C# и эталонных сборок .NET Framework с NuGet, собирает Release и создаёт переносимый архив. Visual Studio устанавливать не требуется. Для первого запуска скрипта нужен доступ к NuGet.

Если инструменты уже загружены в другую папку, её можно указать параметром ToolCache:

    .\Build.ps1 -ToolCache ..\.build-tools -Test

Альтернативно откройте RemnantSaveManager.sln в Visual Studio с инструментами разработки WPF/.NET Framework 4.7.2 и соберите конфигурацию Release.

## Проверки

    .\Build.ps1 -Test

Tests/LocalizationChecks.cs проверяет полноту переводов на основе скомпилированного EXE, чтение встроенного справочника без внешнего XML, порядок событий кампании, приключения и DLC, заголовки WPF, русский экспорт, сохранение значений настроек и английских названий для вики.

Тестовые сохранения, отчёты и изображения окон создаются только в .test-run внутри проекта. Проверки используют искусственные данные; чтение и изменение настоящих игровых сохранений в них не предусмотрено.

## Руководство со снимками интерфейса

Описание интерфейса находится в [русской Wiki](https://github.com/PavelZagumenkin/RemnantSaveManager_Razzmatazzz_RU/wiki) и в [копии руководства](docs/wiki/Home.md).

Для повторного получения снимков из скомпилированной программы сначала выполните Build.ps1, затем:

    .\Tools\Update-WikiScreenshots.ps1

При использовании внешнего кеша укажите тот же параметр ToolCache, что и при сборке. Снимки сохраняются в docs/wiki/images. Инструмент отображает реальные WPF-элементы на демонстрационных данных; файлы демонстрационных сохранений и исполняемый инструмент размещаются в .test-run/wiki.
