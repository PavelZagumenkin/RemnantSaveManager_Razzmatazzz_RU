# Remnant Save Manager 1.101.0 — русская версия, выпуск 1

Первый русский релиз на основе [Remnant Save Manager 1.101.0](https://github.com/Razzmatazzz/RemnantSaveManager/releases/tag/1.101.0). Версия исполняемого файла: **1.101.0.1**.

## Что изменилось

- Переведены интерфейс, меню, подсказки, диалоги, таблицы и журнал.
- Переведены все данные комплектного справочника версии 40: предметы, события, локации, классы, категории, режимы и условия получения.
- Экспорт Markdown и копирование результатов работают на русском языке.
- Русский каталог и запасной игровой справочник встроены в EXE.
- Экран настроек адаптирован под русские надписи; даты и числа используют ru-RU.
- Проверка обновлений программы подключена к этому репозиторию. Игровой справочник обновляется из оригинального проекта.
- Добавлены русский README, инструкция, скрипт сборки и проверки локализации.

## Скачать

- **rsm-1.101.0-ru.1.zip** — рекомендуемый вариант: программа, конфигурация, игровой справочник, инструкция и лицензия.
- **RemnantSaveManager.exe** — отдельный исполняемый файл со встроенным переводом и запасным справочником.

Распакуйте ZIP и запустите RemnantSaveManager.exe. Требуется Windows с .NET Framework 4.7.2 или новее. Программа предназначена для **Remnant: From the Ashes**.

## Проверки

Release-сборка и **1258 проверок на искусственных сохранениях** прошли: встроенный каталог, скомпилированные окна WPF, события кампании, приключений и DLC, настройки, ссылки на вики и русский экспорт.

Новые записи, отсутствующие в русском каталоге, требуют дополнения перевода. Английские названия сохранены для ссылок на оригинальную вики; названия в интерфейсе переведены для этой сборки.
